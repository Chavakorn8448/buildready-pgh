- Real but engine-only: the Ask panel answers shown are the **cached showcase answers produced by the engine-only router** (labeled on screen "Cached showcase answer"). If a Claude API key was added before recording, regenerate with `npm run ask-cache` and the label changes to Claude + engine tools.
